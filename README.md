### 📌 Project Overview
This lab expands the BiteBox website by adding a functional **Cart page** and upgrading the **Contact page** into a professional multi-section layout.

---

### ✨ What Was Added

**Cart Page (`cart.html`)**
- Cart hero section
- Shopping cart table (Item, Price, Quantity, Total, Action)
- Quantity increase/decrease buttons
- Delete item option
- Order Summary (Subtotal, Delivery, Packaging, Total)
- Proceed to Checkout button
- Continue Shopping & Clear Cart actions
- Full professional footer

**Contact Page (`contact.html`)**
- Contact hero section
- Contact info cards (Address, Phone, Email, Social Media)
- Business Hours table
- Catering / Special Events section
- Contact form (Name, Email, Phone, Subject, Message)
- Google Maps section
- Cart icon in navigation
- Full professional footer
